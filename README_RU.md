# Nemexia Raid Manager 1.1

## Запуск в Windows

Поддерживаются **Python 3.10 x64** и **Python 3.11 x64**. Установленные версии можно посмотреть командой `py -0`.

1. Для первого запуска выполните `install.bat`. Скрипт найдёт Python в порядке: `py -3.11`, `py -3.10`, `python`, `python3`; затем создаст `.venv` в папке приложения и установит зависимости.
2. Для обычного запуска используйте `run_app.bat` или `launcher.bat`. `launcher.bat` сам запустит установку, если `.venv` ещё нет.
3. Чтобы переустановить зависимости, закройте приложение, удалите только папку `.venv` в каталоге программы и снова выполните `install.bat`.

Все зависимости устанавливаются только в `.venv`; системный Python и пользовательская SQLite-база не изменяются.

Windows-приложение для управления рейдами Nemexia через отдельный профиль Яндекс Браузера.

## Что умеет

### Надёжность

- подключается к вкладке через Chromium DevTools Protocol;
- перед каждым действием повторно проверяет соединение;
- проверяет исходную планету, количество мегатранспортировщиков и ответ игры;
- подтверждает отправку по новой строке в таблице полётов;
- при ошибке сохраняет скриншот страницы в `%LOCALAPPDATA%\NemexiaRaidManager\screenshots`;
- пишет вращаемый журнал в `%LOCALAPPDATA%\NemexiaRaidManager\logs`;
- автоматически создаёт резервные копии базы.

### Цели и отчёты

- импортирует все страницы административных сообщений прямо из браузера;
- импортирует сохранённые ZIP/HTML-архивы;
- хранит только координаты, игрока, энергию и служебные данные;
- металл, минералы, газ и текущие ресурсы не сохраняются и не влияют на рейтинг;
- поддерживает ручное добавление, изменение, отключение и чёрный список.

### Планирование

- получает фактическое время полёта от самой игры;
- рейтинг учитывает энергию, полный цикл и время с последнего рейса;
- формирует очередь заданного размера, например 45 целей;
- позволяет менять порядок, удалять цели и пересобирать очередь;
- поддерживает подготовку рейса без финальной отправки.

### Отправка

- одиночный рейс;
- волна на все свободные слоты;
- по умолчанию 25 мегатранспортировщиков и 15 слотов;
- автоматический режим берёт по одной цели из очереди;
- автоотправка выключена по умолчанию и отключается при первой ошибке.

### Контроль

- реальные таймеры прибытия и возврата;
- история отправок и ошибок;
- экспорт истории в CSV;
- уведомление при освобождении слота;
- сворачивание в системный трей;
- тёмный интерфейс: Дашборд / Очередь / Активные / Цели / История / Настройки / Лог.

## Первый запуск

1. Распакуй папку, например в `D:\NemexiaRaidManager`.
2. Запусти `install.bat`.
3. Запусти `run_app.bat`.
4. Нажми **«Запустить браузер»**.
5. В отдельном профиле войди в Nemexia.
6. Нажми **«Подключиться»**.
7. Импортируй отчёты или оставь стартовую базу из 49 целей.
8. Нажми **«Рассчитать времена»**.
9. Создай очередь и сначала отправь один тестовый рейс.

## Где хранятся данные

```text
%LOCALAPPDATA%\NemexiaRaidManager\
├── nemexia.sqlite3
├── yandex-profile\
├── backups\
├── logs\
└── screenshots\
```

Обновление файлов программы не удаляет базу, историю и профиль браузера.

## Сборка EXE

На Windows запусти `build_exe.bat`. Скрипт установит PyInstaller и создаст:

```text
dist\NemexiaRaidManager.exe
```

Windows EXE нельзя корректно собрать из Linux обычным PyInstaller, поэтому в архиве лежит готовый сценарий локальной сборки.

## Безопасная проверка

Первый запуск после обновления:

1. автоотправка выключена;
2. нажми «Подготовить» — поля должны заполниться без отправки;
3. отправь одну цель;
4. проверь координаты, количество кораблей и таймер;
5. только после этого проверяй волну.

Программа не обходит капчу, повторную авторизацию и ограничения игры.


## Астероиды

Экран **«Астероиды»** автоматизирует добычу газа с движущихся астероидов:

1. выбирает Питер `[3:39:8]`;
2. сканирует третью галактику строго от системы 39 вниз до 1;
3. получает серверное время следующего перемещения и период движения;
4. выбирает заданное количество переработчиков, по умолчанию 5;
5. рассчитывает точное время через штатную форму Nemexia;
6. прогнозирует положение астероида на момент прилёта;
7. отправляет волну и подтверждает появление каждого рейса в таблице полётов.

Переход через границу клетки рассчитывается без отдельного исключения:

```text
3:38:24 → 3:39:1
3:39:24 → 3:40:1
```

### Автопродление

После отправки волны программа берёт фактическое время возврата самого позднего рейса, добавляет настраиваемый запас — по умолчанию 5 минут — и запускает следующий цикл автоматически.

Автопродление немедленно останавливается, если:

- появилась CAPTCHA / «Are you human?»;
- игра не подтвердила отправку новой строкой полёта;
- закончились свободные слоты или переработчики;
- возникла ошибка, которую нельзя безопасно повторить.

Проверку человека программа **не решает и не обходит**. После ручного прохождения CAPTCHA автопродление нужно включить снова.

### Первый тест астероидов

1. Открой вкладку «Астероиды».
2. Оставь лимит `1` рейс и `5` переработчиков.
3. Нажми «Сканировать» и проверь найденную координату и время движения.
4. Нажми «Рассчитать волну» и сравни время с браузером.
5. Отправь одну волну вручную.
6. После проверки увеличь лимит и только затем включай автопродление.
