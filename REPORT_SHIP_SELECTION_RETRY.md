# Повтор при ошибке выбора кораблей

## Поведение

В `BrowserWorker.send_raid()` добавлен один контролируемый повтор только для сообщений игры:

- `Не выбраны корабли`;
- `Корабли не выбраны`;
- `Не выбрано ни одного корабля`.

После первого такого отказа программа:

1. проверяет, что для той же координаты не появился новый активный рейс;
2. подтверждает только игровое окно `#dialogMessage` кнопкой `OK`;
3. использует встроенную игровую кнопку `Назад` (`showTab('TabChooseShips')`), а не историю браузера;
4. повторно очищает выбор кораблей, выставляет переданное вызывающим кодом число МТ (в обычной настройке — 25), задаёт ту же цель и повторяет отправку один раз.

Если второй раз возникает та же ошибка, если игра вернула другую ошибку, если окно `OK` не найдено или если рейс мог уже быть принят, повтор не выполняется. Волна останавливается стандартным существующим механизмом.

## Почему это безопаснее простого повторного клика

- Нет бесконечных повторов: максимум две попытки отправки одной цели.
- Не используется `history.back()`: в Nemexia кнопка «Назад» переключает игровую вкладку выбора кораблей.
- Перед повтором проверяется отсутствие нового рейса на эту координату.
- Обрабатывается только точная ошибка выбора кораблей, а не любое сообщение сервера.

## Проверка

- `py -m py_compile browser.py self_test.py` — успешно.
- `py self_test.py` — успешно.
- Добавлены тесты: распознавание нужной ошибки; ровно две попытки с теми же координатами и количеством 25; остановка после второй такой ошибки.

Живая отправка и нажатие `OK` в Nemexia для проверки не выполнялись.
