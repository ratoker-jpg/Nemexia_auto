# План отправки по металлу

## Что изменено

- Раздел и навигация `Очередь` переименованы в `План отправки`.
- Рекомендованные цели и новый план формируются только по последнему сохранённому шпионскому отчёту:
  - цель включена;
  - цель не в чёрном списке;
  - цель не находится в активном полёте;
  - в отчёте есть металл и дата разведки;
  - металл не меньше заданного порога.
- Порог по умолчанию — **480 000 металла**. Его можно изменить в настройках в поле `Мин. металл для плана`.
- Сортировка строгая: больше металла — выше строка. При равном металле используется стабильный порядок по координатам.
- Список разведки и таблица целей также показывают первыми цели с большим количеством металла; для каждой координаты используется только самый свежий разведотчёт.
- После подтверждённого `Обновить разведку` локальная история разведок очищается, новые данные сохраняются и план автоматически пересобирается по металлу.
- В плане цветом и статусом выделяются строки `В полёте`, `Отправка`, `Отправлено` и `Ошибка`.
- Добавлены защищённые координаты `3:2:8` (Pegasus Team) и `1:20:19` (`***`). Они принудительно помечаются как исключённые, не участвуют в расчётах, планировании, ручной/автоматической отправке, импорте и отображении шпионских отчётов.
- Существующие записи разведки по защищённым координатам не удаляются: они скрыты из рабочего списка. При «чистом обновлении разведки» их локальные и игровые сообщения также не включаются в очистку.

## Почему появлялись повторы

Схема базы разрешала одинаковую координату в разных состояниях (`queued` и `sending`). При пересборке удалялись обычные строки, но строка `sending` оставалась, после чего та же цель добавлялась заново как `queued` с нумерацией от 1. Поэтому в таблице были одинаковые координаты и повторяющиеся номера.

Теперь миграция оставляет одну строку на координату (приоритет у активной отправки), выравнивает номера и создаёт уникальный индекс по координате. При последующих пересборках отправляемая цель не добавляется повторно, а остальные строки получают последовательные номера.

## Что не менялось

- Не менялись селекторы Nemexia, переходы браузера и способ отправки флота.
- Не запускалась автоотправка и не выполнялись реальные рейсы.
- Ручной выбор строк, изменение их порядка и отправка выбранной волны сохранены.

## Уточнение выбора волны

- Двойной клик по строке плана больше не запускает отправку. Раньше он вызывал команду `Отправить следующий`, которая по смыслу выбирает первую цель по приоритету, а не строку под курсором.
- В первом столбце плана появились галочки `☐` / `☑`. Нажатие на галочку отмечает ровно эту строку.
- `Отправить отмеченную волну` отправляет только отмеченные цели. Если ничего не отмечено, программа просит отметить цели, а не подменяет их первыми строками плана.
- `Отправить следующий` остаётся отдельной командой для первой доступной цели по приоритету металла.
- При подготовке волны строка плана и цель передаются одной парой. Пропуск устаревшей строки не может сдвинуть координаты остальных выбранных целей.
- Галочка меняет только символ в уже видимой строке: ручная сортировка по заголовку и положение таблицы больше не сбрасываются.
- Добавлена команда `Снять зависшие статусы`. Она сначала читает реальные активные рейсы из браузера, затем переводит из `Отправка` в `Готов` только координаты, которых в активных рейсах нет. Без успешной проверки браузера статусы не меняются.
