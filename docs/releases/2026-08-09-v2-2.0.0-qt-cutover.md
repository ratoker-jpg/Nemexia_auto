## Storage

V2 SQLite schema: **9**.

V2-owned runtime storage:

```text
%LOCALAPPDATA%\NemexiaRaidManagerV2\
```

Legacy storage remains separate under `%LOCALAPPDATA%\NemexiaRaidManager\` and is opened by V2 read-only using `mode=ro` and `PRAGMA query_only=ON`.

Production V2 startup/shutdown creates the release-gated backup boundaries and closes the database/context deterministically. Restart recovery preserves unresolved pending/ambiguous journals rather than reopening remote side effects for automatic retry.

## Install / upgrade

Clean install:

```text
install.bat
run_app.bat
```

The installer builds one local `.venv` containing dependencies required for both the Qt production runtime and explicit legacy rollback.

Existing-user upgrade is release-tested with isolated temporary `%LOCALAPPDATA%` roots. The gate verifies accepted legacy imports into V2, byte-integrity of the legacy DB where the contract requires it, V2 restart persistence and DB unlock after shutdown.

## Deliberate limitations — not release blockers

`NO NAVIGATION BOUNDARY` remains authoritative. Release 2.0.0 does not implement or silently enable:

- automatic 3×40 traversal;
- background browser navigation;
- Rest Mode navigation loops;
- automatic `refreshGalaxy`;
- V2 `change_planet.php`;
- arbitrary V2 `page.goto` navigation;
- automatic browser launch/new-tab ownership;
- CAPTCHA solve/click/bypass;
- automatic message deletion;
- automatic retry after ambiguous remote side effect;
- creation of a new espionage route when no exact processable spy fleet exists;
- unattended asteroid/debris scheduler;
- V2-68, V2-69 or V2-70 navigation work.

These remain separate future feature contracts.

## Mutation safety retained

- Raid/asteroid/debris execution remains typed, prepared/rechecked, journaled and limited to exactly one remote mutation attempt per accepted request.
- Ambiguous possible acceptance blocks automatic retry.
- Spy mutation uses an exact existing fleet ID, never `processSpy(0)`.
- CAPTCHA remains detect → STOP.
- AutoFarm arm and exact Spy fleet ID remain session-only; explicit Start is required.
