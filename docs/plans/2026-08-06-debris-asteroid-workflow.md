# Астероиды с обломками — реализованный контракт

## Назначение

Функция находит астероиды, чья подсказка содержит фразу `Этот астероид содержит обломки`, сохраняет полученный список и позволяет вручную отправить переработчиков на выбранные строки.

## Сканирование

- галактики: 1, 2, 3;
- системы: 40 → 1;
- всего: 120 систем;
- поиск выполняется через существующий `squareInfo`;
- CAPTCHA останавливает операцию;
- между системами используется небольшая пауза;
- завершённый скан заменяет предыдущий сохранённый список;
- остановленный пользователем неполный скан отображается только в текущем сеансе и не заменяет последний полный результат.

## Отправка

- пользователь выделяет одну или несколько строк;
- количество переработчиков на рейс настраивается отдельно, по умолчанию 100;
- новый запрос информации об астероиде перед отправкой не выполняется;
- используется сохранённое время последнего и следующего перемещения;
- непосредственно перед каждым рейсом игра заново рассчитывает время полёта;
- будущая позиция астероида рассчитывается существующей итерационной формулой до стабилизации координат;
- учитывается запас до границы движения;
- операция проверяет свободные слоты и общее количество доступных переработчиков;
- ответ сервера и новая строка полёта проходят уже существующий строгий verification gate;
- при CAPTCHA, неподтверждённой отправке или другой ошибке серия останавливается.

## Ограничения

- используется существующая миссия переработчиков для астероидов;
- функция не запускает автоматические повторные циклы;
- обычная автоотправка и астероидное автопродление должны быть выключены;
- реальная Windows/Nemexia проверка выполняется после обновления локальной копии.
